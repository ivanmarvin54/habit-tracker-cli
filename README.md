# CLI Habit Tracker 🎯

Консольное приложение на Python для отслеживания ежедневных привычек. 

## 🚀 Возможности
- Добавление новых привычек
- Отметка выполнения на сегодняшний день
- Просмотр списка привычек и количества выполнений
- Удаление привычек по номеру
- Просмотр статистики (серия дней подряд, процент выполнения)
- Данные сохраняются в локальный файл `data.json` и не теряются при перезапуске

## 🛠 Технологии
- Python 3 (стандартная библиотека)
- JSON для хранения данных
- Модули `datetime` и `pathlib`
